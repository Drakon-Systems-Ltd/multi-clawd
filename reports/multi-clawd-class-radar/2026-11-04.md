## Method and limits

- Sources are public GitHub release notes, pull request descriptions, commit titles and READMEs, plus repository metadata from the public `GET /repos/{owner}/{repo}` endpoint. OpenClaw and ClawHub were not re-read this week; the 2026-10-28 findings are carried forward unchanged and are not re-verified.
- Every competitor capability is **what the project's own text says**. Nothing was installed or run, no credentials were used, no provider calls were made.
- multi-clawd facts come from `origin/master` at `57d66c8` (package.json 2.6.4), `CHANGELOG.md`, a source grep, and the npm registry, checked live on the observation date.
- Gap rule, unchanged: file only if at least two independent public tools document the capability, multi-clawd lacks it, and no existing issue (open or closed) covers it.

## What changed in the class since 2026-10-28

- **teamclaude** v1.1.27 (2026-10-31), a large release. Among its notes: billing-refusal failover (a depleted credit balance puts the account in a 5-minute cooldown and the request moves on, PR #626), a bounded quota series with a forecast of when the fleet runs out (#578), an opt-in "pressure" placement score (#577), a drain mode, request-id correlation, probing of disabled accounts to keep quota fresh (#612), recording that a subscription meters no 5-hour window (#622). https://github.com/KarpelesLab/teamclaude/releases/tag/v1.1.27 and https://github.com/KarpelesLab/teamclaude/pull/626
- **claude-swap** v0.29.0 (2026-10-28), already summarised last week; v0.28.0 (2026-10-22) adds a separate weekly threshold and a per-account switch line, plus atomic writes. https://github.com/realiti4/claude-swap/releases/tag/v0.28.0
- **clauth** v0.18.1 (2026-11-02) and v0.18.2 (2026-11-03): credit refusal tracking (an account that refused a credit-billed request is passed over for work that may need credits), a usage probe for setup-token accounts, live session listing, background fallback sessions, advisor-model support. https://github.com/uwuclxdy/clauth/releases/tag/v0.18.1
- **maxpool** v1.24.66 (2026-11-02), thirty-odd releases in a week: team/cloud pool linking, a reset policy, queue-never-fail holds, Ultra no-5h pinning. Release notes are one-line commit titles. https://github.com/2solarmax/maxpool/releases
- **claude-auto-switch (`ccx`)** 2.6.28 (2026-10-28): macOS Keychain and editor-folder housekeeping (commit titles).
- **asyncdargen/claude-proxy** (2026-11-01 to 2026-11-02): account plans, API-key upstreams, per-account proxies, CGNAT treated as internal (commit titles).
- **Timo972/cc-router**: an endpoint to look up the account bound to a session (commit titles, 2026-10-22 to 2026-10-29).
