# multi-clawd class radar: 2026-10-21

Second weekly public-source radar (issue #67), following the 2026-10-18 radar (#49). Sources were observed on **2026-10-21 (UTC)** between 07:07 and 07:12.

## Method and limits

- Sources are public GitHub READMEs and docs pages fetched raw, public OpenClaw docs, the ClawHub topic pages, and web-search result lists used only to discover candidates. Repo metadata (last push, stars, licence) comes from the public `GET /repos/{owner}/{repo}` endpoint on the observation date.
- Every competitor capability below is **what the project's own documentation says**, not something that was verified. Nothing was installed or run, no credentials were used, and no provider calls were made.
- multi-clawd facts come from this repo at `577ba92` (`master`, v2.4.0, merged and not yet published). Each one cites a file.
- Gap rule, unchanged from the first radar: a capability is filed as a class gap only if at least two independent public tools document it, multi-clawd does not have it, and no existing multi-clawd issue covers it.
- The ClawHub `multi-account` topic page returned "plugin catalog is temporarily unavailable" on this run; the `failover` topic page listed multi-clawd alone. Any other OpenClaw plugin in this class could not be confirmed either way today.

## What changed since 2026-10-18

All four gaps filed last time are closed and shipped: reset-aware selection (#54, v2.3.0), separate weekly threshold (#55, v2.2.0), per-session affinity (#56, v2.4.0) and account benching (#57, v2.4.0) (`CHANGELOG.md`). The comparison table below therefore starts from a stronger baseline.

Competitor movement observed in the same window:

- teamclaude is renaming to TeamRouter across several releases, documents organisation-bound thinking blocks for Sonnet 5.5 conversations that cross accounts, and now takes one failover hop on a plain rate-limit 429 and on 5xx (README and `docs/routing.md`).
- claude-swap added a per-account switch-away threshold, `consume-first` strategy, directory-to-account mapping and a macOS menu bar app (README).
- maxpool now has a cross-provider `all` profile (GLM, Kimi), graceful drain on restart and a 24h hold on weekly exhaustion gated on real reset times (README).
- Five tools not in the first radar were found: nextclaude, claude-auto-switch (`ccx`), swisscode, asyncdargen/claude-proxy and the D1DX fork of teamclaude. clauth's default branch is `mommy`, which is why its README fetch failed last time.

OpenClaw-side context: core rotates its own `anthropic` auth profiles with per-session pins and cooldowns, and applies bounded same-model recovery for temporary rate limits before rotating (https://docs.openclaw.ai/concepts/model-failover).
