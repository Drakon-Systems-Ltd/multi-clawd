## What changed in the class since 2026-10-21

- **claude-swap** v0.29.0 (2026-10-28): opt-in account priority tiers with `priority-consume-first`; when every account is over its switch lines it now moves to the one with the most room left; `run.shareHistory` default; quieter macOS child spawning. https://github.com/realiti4/claude-swap/releases/tag/v0.29.0
- **teamclaude** v1.1.26 (2026-10-20, the latest release): `distribute load` placement by recent request count, `switch --session` to move one running session, `maxUsage` hold on every selection path, honour for upstream non-retryable 429s. https://github.com/KarpelesLab/teamclaude/releases/tag/v1.1.26 No commits on master after 2026-10-20 (GitHub shows a later push timestamp, unexplained).
- **clauth** v0.18.0 (2026-10-25): live token speed, shunt gateway management inside the TUI, preset model binds, a usage-credit gate that keeps auto-switch off accounts whose usage-credit cap is spent. https://github.com/uwuclxdy/clauth/releases/tag/v0.18.0
- **maxpool** v1.24.34 (2026-10-27): detection of a key used outside the pool for one provider, reset-card hold policy, a release stage watchdog. https://github.com/2solarmax/maxpool/releases/tag/v1.24.34
- **claude-auto-switch (`ccx`)** 2.6.27 (2026-10-24): macOS Keychain and session-folder housekeeping only (commit titles).
- **asyncdargen/claude-proxy**: model-scoped 429s no longer park the whole account; self-updating model catalogue (commit titles, 2026-10-22 to 2026-10-26).
- Retired: wakaka6/claude-code-relay is now archived (API `archived: true`). nextclaude has had no push since 2026-06-10.
